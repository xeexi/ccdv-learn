9-2　公式の例題 ─ 誤答には型がある

ゴール例題の誤答を型で見分け、間違えたときに戻る項を選べる。

公式 Exam Guide には、解説つきの例題が付いています。この教材では例題を訳して載せず、誤答がどんな形で作られているかを型に分けて載せます。本番の誤答も、同じ型で作られています。例題の原文は、トップの〈参考資料〉から Exam Guide で読めます。

誤答の型（9個ぶんを分類）こう見えるなぜ誤りか
① 効かないつまみを回す
9個中 3個		 並列にする／max_tokens を下げる／temperature を上げる 動かしているのは、問われている軸とは別のつまみ
公式の解説より ─ “does not address the batch-versus-realtime tradeoff”
② モデルの大小で片づける
9個中 2個		 いちばん小さいモデルにする／大きいモデルにする モデルを替えても仕組みの問題は残る。指示に従順なモデルほど注入に弱いこともある
公式の解説より ─ “a more instruction-following model (D) can be more susceptible, not less”
③ 頼んで守らせる
9個中 1個		 system に「〜しないで」と書く お願いは強制力のある制御ではない
公式の解説より ─ “a polite request (C) is not an enforceable control”
④ その場しのぎで使い回せない
9個中 2個		 プロンプトに書き込む／データを毎回貼る 動きはするが、使い回せず保守もできない。貼ったデータは古くなり窓を食う
公式の解説より ─ “Hard-coding logic into prompts (A) is neither reusable nor maintainable”
⑤ 事実で消える
9個中 1個		 組み込みツールが何でも届く、のような機能の誤解 知っていれば読んだ瞬間に消える。考える前に、まずこれを外す
公式の解説より ─ “built-in tools (D) do not automatically reach arbitrary internal APIs”

ポイント3問の誤答9個は、この5つで全部説明がつく。最も多いのは① 効かないつまみを回す（3個）。
