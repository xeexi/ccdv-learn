9-4　受験の準備 ─ 公式が勧めること

ゴール公式が勧める準備を、この教材のどの項で進めるかを言える。

公式 Exam Guide は、準備として、読むことだけでなく実際に作って動かすことを勧めています。試験が問うのは、作ったことのある人の判断だからです。

準備中身（下は原文）対応する項
自己評価 ブループリント（§6）を読み、スキルごとに自分の理解を確かめる。トップの表の「扱う項」から各項へ戻れる
“Study the exam blueprint in Section 6 and self-assess against each objective”		 ─
文書を読む API・モデル・プロンプト・Claude Code・Skills・MCP の公式ドキュメントを読む
“Review official Anthropic documentation for the Claude API, models, prompt engineering, Claude Code, Skills, and MCP”		 2-1 5-9 6-2 3-1 8-8 8-5
1つ作る API を使い、道具を1つ以上つなぎ、プロンプトと文脈を整え、簡単な守りと評価を入れたアプリを、作って動かす
“Build and operate at least one Claude application that exercises the API, integrates one or more tools, applies basic prompt and context engineering, and includes simple security and evaluation practices”		 1-4 8-2 6-1 6-5 7-1 6-3
練習する プロンプトと system・エージェントとワークフロー・Claude Code の設定・トークンと費用・ガードレール・自作の道具や MCP サーバを、手を動かして練習する
“Practice the developer competencies: writing prompts and system instructions, building agents and workflows, configuring Claude Code, managing tokens and cost, implementing guardrails, and creating custom tools or MCP servers”		 6-1 1-1 3-2 5-10 7-3 8-1 8-5
例題を解く 例題（§8）を解き、設問の形に慣れる
“Complete the sample questions in Section 8 to familiarize yourself with item style”		 9-2

ポイント読んで分かったつもりの項ほど、小さなアプリを1つ作って確かめる。作ると、どこで判断が要るかが分かる。

申し込みと当日

ゴール受験の手続きで、行動が変わる決まりを言える。

受験の実務 ─ 計画に効くものだけ 予約する前に　身分証の氏名と登録名が完全に一致している必要があります。訂正は certifications-support@anthropic.com へ ── 予約する前に済ませます。配慮（accommodations）が要るときも、Pearson VUE の承認を得てから予約します。
受け方　オンライン監督つき、またはテストセンター（Pearson VUE）。受験料 125 USD。予約の変更・取消は24時間前まで。それを過ぎたとき、および無断欠席・遅刻は、受験料が戻らず登録し直しになります。
当日　写真つきの本人確認書類が要ります。机の上に資料・端末は置けません（携帯・スマートウォッチ・ヘッドホン・参考書・録音機器も持ち込めません）。試験内容は口外しないという同意（NDA）に応じてから始まります。
落ちたとき　待機は14日 → 30日 → 90日と伸びます。直近12か月で受けられるのは4回まで。1回目で通す前提で組むほうが安上がりです。
受かったあと　有効期間は12か月。期限内なら無料の更新試験で更新でき、切らすと本試験を受け直しになります。
