CLAUDE CERTIFIED DEVELOPER ─ FOUNDATIONS

CCDV-F 学習ノート

この試験が問うのは、Claude を使ったアプリケーション・エージェント・ワークフローを作り、組み込み、本番に出すための判断です。API での組み込み、ツールとエージェントの組み立て、プロンプトとコンテキストの設計、評価、セキュリティ、モデルの選び方までが範囲に入ります。

本試験は 53問・120分、合格は 100〜1,000 の尺度で 720。出る範囲は公式 Exam Guide のブループリント（ドメインと、その中のスキル）で決まっていて、この教材はそれを目次にしています。
設問は1つ選ぶものと、複数選ぶものが混じり、何個選ぶかは設問に書かれています。
採点は他の受験者との比較ではなく、決められた水準に達したかで決まります。結果にはドメインごとの正答率も出ますが、合否は総合点だけで決まります。
