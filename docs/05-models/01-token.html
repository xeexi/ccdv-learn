5-1　次の1トークンを選び続ける

ゴール同じ入力でも答えが変わる理由を、トークンと確率で説明できる。

Claude は、答えの文章を先にまとめて決めてから書いているのではありません。文章を細かく刻んだ単位（トークン）を1つずつ、「次に来そうなもの」から選んでは後ろに繋げています。

DOMAIN 5LLM Fundamentals

ポイント生成は「次の1トークンを確率で選ぶ」ことの繰り返し。文全体は、この選択を重ねた結果としてできあがる。

トークン ─ 数えるのも、払うのも、この単位

ゴール文字数ではなくトークン数で考える理由を言える。

トークンは、単語や文字の断片です。どこで区切るかはモデル側の決まり（トークナイザ）で決まり、同じ文でも、モデルが変われば数が変わることがあります。

モデルが一度に扱える量も、出力の上限も、料金も、すべてトークンで数えます。文字数から見積もるとずれるので、実際の数は API に数えさせます（〈トークンを数え、費用を見積もる〉）。

揺れは消せない ─ サンプリングと非決定性

ゴール揺れを前提にした確かめ方を選べる。

確率に従って1つ選ぶことをサンプリングと言います。確率の高い候補ほど選ばれやすいものの、いつも最も高いものが選ばれるわけではありません。そのため同じ入力でも、出力が同じになる保証はありません。この性質を非決定性と呼びます。

選び方の散らばりを調整する値（temperature など）を受け付けるモデルもあります。ただし最も低くしても、毎回同じ答えになる保証はなく、答えが正しくなるわけでもありません。新しい世代には、この値の指定そのものを受け付けないモデルもあります。

起きること理由
答えの揺れ選ぶ道筋が、確率で回ごとに変わる。言い回しだけでなく、結論が変わることもある
ない関数名「それらしい並び」を選んだ結果。事実と照らし合わせて書いているわけではない
断定の誤り口調もまた、もっともらしさで選ばれる。口調と正しさは関係しない
誤解「temperature を最も低くすれば、テストで完全一致を期待できる」 実際は揺れはなくならない。決まった文字列と比べるのではなく、形や含むべき内容を確かめ、必要なら何回か流して判定する。

ポイント揺れと、もっともらしい誤りは消せない。確かさが要るところは、モデルの外側（検証・仕組み）で受ける。
