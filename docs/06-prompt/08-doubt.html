6-8　自信のある出力ほど疑う

ゴールもっともらしい誤りを、確かめ方と止め方で防げる。

口調の確かさと、中身の正しさは関係しません（〈次の1トークンを選び続ける〉）。確かさが要るところでは、出力をそのまま信じず、確かめる仕組みを先に組みます。

DOMAIN 6Output Handling

手すること
不明を許す分からないときは「分からない」と答えてよい、と明示する
引用を先に長い資料から、根拠になる箇所を一字一句抜き出させてから答えさせる
出典を示す主張ごとに出典を示させ、支える箇所が無い主張は取り下げさせる。Citations の機能を使うと、資料の該当箇所を指させられる
資料に限る渡した資料だけを根拠にするよう指示する
何回か出す同じ問いに何回か答えさせ、答えが割れたら疑う
外で検証コードはテストで、計算は計算で、事実はツールで確かめる

ポイント減らす手はあっても、もっともらしい誤りはなくならない。確かさが要る出力は、使う前に外で確かめる。

自信と正しさは別

ゴール自信のある口調の出力でも、確かめが要る理由を言える。

Claude は、もっともらしい続きを選んで書きます。存在しない関数名や、ありそうな数字も、同じ滑らかさで書かれます。口調が確かなことは、確かめなくてよい理由になりません。

コードの作業では、開いていないファイルの中身を推測させず、必ず読ませてから答えさせます。

誤解「自信ありげに、はっきり答えた出力は正しい」 実際は口調も、もっともらしさで選ばれている。確かさは、出典やテストで外から確かめる。
