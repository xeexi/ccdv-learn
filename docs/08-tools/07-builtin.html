8-7　組み込みのツールか、自作か

ゴール組み込みツールと自作ツールを、届く範囲と手間で選び分けられる。

Claude に道具を足す手は4つあります。組み込みのツール・自作のツール・Skills・MCP です。まず、はじめの2つを比べます。

DOMAIN 8Agentic Customization

手何か向くとき限り
組み込みAnthropic が用意した道具。web search や code execution のように Anthropic 側で動くものと、bash や text editor のように形だけ決まっていて実行はアプリのものがある検索・コードの実行・ファイル操作など、よくある作業を手早く足す社内のシステムには届かない
自作名前・説明・入力の形を自分で定義し、実行もアプリで行う社内の API やデータベースを呼ぶ。承認や記録を挟みたい操作そのアプリの中でしか使えない

ポイントよくある作業は組み込みで足り、社内のシステムに触れるなら自作する。組み込みのツールが、社内の API に勝手に届くわけではない。

何でもできる道具か、専用の道具か

ゴールbash のような広い道具から、専用のツールに切り出す場面を言える。

bash は、ほとんど何でもできる広い道具です。ただしアプリから見ると、どの操作も同じ「コマンドの文字列」で届くので、中身を見分けられません。操作を専用のツールに切り出すと、その操作だけに型の付いた引数が付き、アプリが扱えるようになります。

切り出す理由できるようになること
止めたい送信や削除のような取り返しのつかない操作だけに、承認を挟める
見せたい利用者への質問を、選択肢つきの画面として出せる
記録したい誰が何をしたかを、操作ごとに残せる
並べたい読むだけの操作を、並列で走らせてよいと判断できる

目安は、まず広い道具で始め、止める・見せる・記録する・並べる必要が出た操作から、専用のツールに切り出すことです。
