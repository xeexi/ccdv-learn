1-8　Agent SDK で作る

ゴールAgent SDK が用意しているものと、自分で書く部分を区別できる。

アプリ→Claude Code→Claude

Agent SDK は、Claude Code を動かしている道具・ループ・文脈の管理を、Python と TypeScript のライブラリとして使えるようにしたものです。ループを自分で書かずに、ファイルを読み書きし、コマンドを実行するエージェントを、自分のアプリに組み込めます。

ポイントループと道具は SDK が持つ。自分で決めるのは、何をどこまで許すか。

自分で決めること

ゴールSDK を使っても自分で決めることを挙げられる。

SDK が用意するのは仕組みで、何をどこまで許すかは自分で決めます。確認なしで動かす道具・承認を求める道具・禁じる道具、ループと費用の上限、CLAUDE.md や Skills のような設定を読み込ませるかどうか、です。

権限の決め方には、あらかじめ書いておく規則、動き方のモード、呼び出しごとに判定する関数があります。禁じる規則は、どのモードでも効きます。

API を呼ぶ SDK との違い

ゴールAgent SDK と、API を呼ぶ SDK（Client SDK）の違いを言える。

比べる点Client SDKAgent SDK
ループ自分で書く（tool runner に任せることもできる）用意されている
道具自分で定義して、自分で実行するファイル・コマンド・検索がそろっている
管理権限・セッション・フックは、自分で作る用意されている
動く場所どこでも（HTTP で API を呼ぶだけ）Claude Code の本体が動ける環境（ファイルとシェル）

Client SDK は、〈SDK は REST を包んでいる〉で扱った、API を呼ぶための SDK です。

誤解「Agent SDK は、API を呼ぶ SDK の新しい名前」 実際は別物。Claude Code と同じ道具とループが入っていて、ファイルを読み書きし、コマンドを実行する。そのぶん、動かす場所の用意が要る（〈どこで動かすか〉）。
